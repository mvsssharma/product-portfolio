Product Overview

GlintPost is a product marketing platform that bridges the communication gap between product teams and their users. It provides lightweight, embeddable widgets for changelogs, roadmap voting, and feedback that drop into any site with a simple script tag — so teams can showcase what they shipped, let users vote on what's next, and collect context-rich feedback without sending anyone off to a separate portal. It's open-source and self-hostable via a single Docker command, while the same codebase also powers a multi-tenant cloud SaaS through runtime feature flags.

Major Product Decisions

Embed-First vs. Standalone Portals

Instead of forcing users to visit a separate subdomain, I prioritized an "embed-first" strategy across all three widgets. Five embed modes — slideover, inline, tab, hosted, and headless — mean a team can surface updates wherever it makes sense, keeping users in the product context and increasing both visibility and feedback rates.

Open-Source First, Cloud Optional

GlintPost ships as a single codebase that powers two environments through 12-factor feature flags. Self-hosters run a frictionless "single-player" mode — one docker compose up, email verification and billing flipped off, password resets falling back to console logs, no third-party API keys required. The same build, with flags on, runs as a multi-tenant cloud SaaS on Vercel with enforced verification and billing.

BYO AI Keys, Encrypted at Rest

Rather than bake in a single AI vendor and eat the token costs, users bring their own keys for OpenAI, Anthropic, or Google. Keys are encrypted at rest with AES-256-GCM. This powers changelog writing assistance and auto-translation while keeping AI spend fully in the customer's control.

Market Differentiation

Datalayer-Native Targeting

Competitors like Canny, Beamer, AnnounceKit, and Featurebase build walled gardens — their own user tracking, their own segment builders, their own analytics silos. GlintPost takes the opposite approach: customers pass their existing GTM/datalayer variables directly, so targeting works with the data they already have. Beta features can be shown only to beta testers, enterprise updates only to enterprise users — with zero new segmentation config.

True GTM Compatibility

The widgets are plain <script> tags with data- attributes, designed to drop into a Google Tag Manager Custom HTML tag trivially — not bolted on as an afterthought. Combined with flat, no-per-seat pricing, GlintPost undercuts the tracked-user billing traps and per-seat add-ons that inflate competitor costs at scale.
